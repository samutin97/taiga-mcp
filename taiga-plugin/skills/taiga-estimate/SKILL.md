Сначала загрузи скилл `taiga-voice`.

# Оценка историй

Шкала, эталоны и правила — в `reference.md`.

## Порядок

1. Допустимые значения: `taiga_project_schema`, `lookups.points`.
2. Эталоны: `taiga_userstory_list` с `is_closed: true` — закрытые истории с
   `points`. Выбери по одной-две на каждое значение шкалы; это точки отсчёта.
3. Для каждой оцениваемой истории назови два ближайших эталона («сложнее #12 на 3,
   проще #7 на 8») и предложи значение из ряда 1, 2, 3, 5, 8, 13.
4. Больше 13 — не оценивать, а предложить, как разрезать (по шагам сценария,
   по типам пользователей, по «сначала вручную — потом автоматически»).
5. Покажи таблицу «история — эталоны — предложение», дождись согласия.
6. Запиши `points` через `taiga_userstory_update` строкой (`"5"`), по одной
   истории за вызов. Пишется в основную роль проекта.

## Чек-лист

- [ ] оценка относительная, а не «в часах»
- [ ] ни одной истории больше 13 — либо разрезана, либо помечена к разрезанию
- [ ] пользователь согласился с таблицей
